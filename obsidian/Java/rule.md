# Rule sử dụng ghi chú Obsidian

- Tất cả rule, hướng dẫn, quy tắc trình bày, liên kết, ví dụ... chỉ ghi tại `.github/copilot-introductions.md`.
- Các file kiến thức chỉ chứa nội dung chuyên môn, ví dụ, câu hỏi, không chứa rule.
- Luôn tạo liên kết giữa các file kiến thức liên quan.
- Ưu tiên mở rộng theo chiều sâu từng chủ đề.

> Xem chi tiết tại [[.github/copilot-introductions.md]]
